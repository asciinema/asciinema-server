# National Park

The asciinema homepage uses **National Park** for uppercase headings at regular
weight (400), with the font's native spacing.

## Provenance

- Upstream: <https://nationalparktypeface.com/> and <https://github.com/benhoepner/National-Park>.
- Distribution: Google Fonts, revision `86aced91de05cd4f96a06838124cca45be337b2b`.
- Source file: <https://github.com/google/fonts/blob/86aced91de05cd4f96a06838124cca45be337b2b/ofl/nationalpark/NationalPark%5Bwght%5D.ttf>.
- Local file: `NationalPark-Variable.ttf`, an unmodified copy of the upstream
  variable font, supporting weights 200 through 800.
- SHA-256: `17699dc82c52b177b95dec6805c8091ab79a965c866fa0f07ffa8672ddde0b5c`.
- License: SIL Open Font License 1.1, included in `NationalPark-LICENSE.txt`.

No font-generation step or custom spacing modifications are needed.
